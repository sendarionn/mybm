# mybm

Chrome標準ブックマークとフォルダに検索、説明、Cosense形式のリンク構造を追加するChrome拡張機能

この拡張機能はCodexを使用して開発しています

## インストール

1. Chromeで `chrome://extensions/` を開く
2. 「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このリポジトリのフォルダを選ぶ

拡張機能名 `mybm` が一覧に表示される

## 使い方

1. ツールバーの拡張機能メニューから `mybm` を開く
2. 一覧の鉛筆アイコンで説明画面を開くか、外部リンクアイコンでブックマークを新しいタブに開く
3. タイトル、URL、説明文、`[]` 内のリンク名で一覧を検索する
4. 説明欄に任意の文章を入力する
5. リンクは `[Mozc]`、階層は行頭の空白で記述する
6. 入力内容はService Workerへ即時送信され、`chrome.storage.local` に自動保存される

説明欄で `[` に続けて文字を入力すると、ブックマーク名と既存リンク名の候補が表示される

上下キーで候補を選び、EnterまたはTabで `]` まで入力する

単一行の文字列を選択して `[` を入力すると、選択文字列を `[]` で囲んでリンクにする

説明欄では `Cmd-Z` で元に戻し、`Cmd-Shift-Z` でやり直せる

保存データにはスキーマ番号とバックアップを付け、mybmの通常更新時に既存の説明文を引き継ぐ

一意に解決できるリンクは、表示名とは別にChromeノードIDとの対応を保存する

ブックマークまたはフォルダの名称が変わると、対応する説明文内のリンク表記も自動更新される

同名ノードへの曖昧なリンクと仮想ノードは自動更新しない

説明編集中の名称変更は通常入力を残して統合し、安全に統合できない場合は競合を表示する

拡張機能自体を削除するとChromeがローカル保存領域を削除するため、説明文も削除される

アドレスバーでは `b` と入力してTabまたはSpaceを押す

続けて検索語を入力すると、タイトル、URL、説明文、リンク文字列に一致する候補が表示される

候補にはブックマークとフォルダが表示される

候補を選択すると、通常のブックマークは指定したタブで開き、ブックマークレットは現在のタブで実行される

フォルダを選択すると同じmybmポップアップ内に詳細が開く

フォルダ詳細では説明文、フォルダ内検索、子要素、Links・被リンクを確認できる

フォルダ内検索が空の場合は直下の子要素を表示し、入力時はすべての子孫を検索する

子フォルダを選択すると同じポップアップ内で移動し、戻ると直前の検索状態へ戻る

Omniboxからフォルダを確定した場合も、新規タブを作らずmybmポップアップを開く

フォルダの説明文も入力内容をService Workerへ即時送信して自動保存する

開始文字列を変更する場合は `manifest.json` の次の値を編集する

```json
"omnibox": {
  "keyword": "b"
}
```

編集後に `chrome://extensions/` でmybmを再読み込みすると、指定した文字列で検索を開始できる

Chromeの制約により、開始文字列は実行中の設定画面から変更できず、空白を含む文字列も使用できない

詳細画面のタイトルをクリックするとChromeブックマークまたはフォルダのタイトルを編集できる

詳細画面のURLをクリックするとChromeブックマークのURLを編集できる

説明欄をクリックすると説明を編集できる

画面上部の `mybm` を選ぶと検索一覧へ戻る

`javascript:` で始まるブックマークレットは、新しいタブではなく現在表示中のWebページ上で実行される

Chrome設定画面など、拡張機能によるスクリプト実行が禁止されたページでは実行できない

ブックマークレットを利用するにはChrome 135以降が必要になる

Chrome 138以降では `chrome://extensions/` からmybmの「詳細」を開き、「ユーザー スクリプトを許可する」を有効にする

説明編集にはCodeMirrorを使用する

IME変換中の入力とEnterには独自処理を加えず、CodeMirrorの入力処理に任せる

`[]` で囲んだリンクは `Links` に表示され、選ぶと同名のブックマークまたはフォルダへ移動する

編集中はカーソル行の `[]` を記法のまま表示し、それ以外の行をリンクとして整形する

行頭に空白がある行は、入力前から常に箇条書き階層として整形する

リンク先が存在しない場合はURLを持たない仮想ノードを表示し、そこへの逆リンクを確認できる

同名のブックマークやフォルダが複数ある場合は自動統合せず、候補を表示する

## 開発

```sh
npm run build
npm test
```

Chromeブックマークとフォルダ本体は変更せず、説明文だけを拡張機能のローカルストレージで管理する
