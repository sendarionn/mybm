# mybm

Chrome標準ブックマークに検索、説明、Cosense形式のリンク構造を追加するChrome拡張機能

この拡張機能はCodexを使用して開発しています

## インストール

1. Chromeで `chrome://extensions/` を開く
2. 「デベロッパー モード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
4. このリポジトリのフォルダを選ぶ

拡張機能名 `mybm` が一覧に表示される

## 使い方

1. ツールバーの拡張機能メニューから `mybm` を開く
2. 一覧の鉛筆アイコンで説明画面を開くか、外部リンクアイコンでブックマークを新しいタブに開く
3. タイトル、URL、説明文、`[]` 内のリンク名で一覧を検索する
4. 説明欄に任意の文章を入力する
5. リンクは `[Mozc]`、階層は行頭の空白で記述する
6. 入力を止めると説明が `chrome.storage.local` に自動保存される

保存データにはスキーマ番号とバックアップを付け、mybmの通常更新時に既存の説明文を引き継ぐ

拡張機能自体を削除するとChromeがローカル保存領域を削除するため、説明文も削除される

アドレスバーでは `mybm` と入力してTabまたはSpaceを押す

続けて検索語を入力すると、タイトル、URL、説明文、リンク文字列に一致する候補が表示される

候補を選択すると、通常のブックマークは指定したタブで開き、ブックマークレットは現在のタブで実行される

開始文字列を変更する場合は `manifest.json` の次の値を編集する

```json
"omnibox": {
  "keyword": "bm"
}
```

編集後に `chrome://extensions/` でmybmを再読み込みすると、指定した文字列で検索を開始できる

Chromeの制約により、開始文字列は実行中の設定画面から変更できず、空白を含む文字列も使用できない

詳細画面のタイトルをクリックするとChromeブックマークのタイトルを編集できる

詳細画面のURLをクリックするとChromeブックマークのURLを編集できる

説明欄をクリックすると説明を編集できる

画面上部の `mybm` を選ぶと検索一覧へ戻る

`javascript:` で始まるブックマークレットは、新しいタブではなく現在表示中のWebページ上で実行される

Chrome設定画面など、拡張機能によるスクリプト実行が禁止されたページでは実行できない

ブックマークレットを利用するにはChrome 135以降が必要になる

Chrome 138以降では `chrome://extensions/` からmybmの「詳細」を開き、「ユーザー スクリプトを許可する」を有効にする

説明編集にはCodeMirrorを使用する

IME変換中の入力とEnterには独自処理を加えず、CodeMirrorの入力処理に任せる

`[]` で囲んだリンクは `Links` に表示され、選ぶと同名のブックマークへ移動する

編集中はカーソル行の `[]` を記法のまま表示し、それ以外の行をリンクとして整形する

行頭に空白がある行は、入力前から常に箇条書き階層として整形する

リンク先が存在しない場合はURLを持たない仮想ノードを表示し、そこへの逆リンクを確認できる

同名のブックマークが複数ある場合は自動統合せず、仮想ノード上に候補を表示する

## 開発

```sh
npm run build
npm test
```

Chromeブックマーク本体は変更せず、説明文だけを拡張機能のローカルストレージで管理する
